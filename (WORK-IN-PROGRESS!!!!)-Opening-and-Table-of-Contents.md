<b>Solstice OS is a GNU/Linux distribution.</b> That means it is an operating system that uses the [Linux kernel](https://en.wikipedia.org/wiki/Linux_kernel), and [GNU tools](https://en.wikipedia.org/wiki/GNU_Project). We will hereby refer to GNU/Linux operating systems as just "Linux distributions" for simplicity.  
<br> 
Most standard Linux distributions use a [binary](https://web.archive.org/web/20250328022813/https://www.reddit.com/r/learnprogramming/comments/lyw9gf/can_someone_explain_what_people_mean_by_binaries/) first [package manager](https://en.wikipedia.org/wiki/Package_manager) (<i>see Debian's [Apt package manager](https://wiki.debian.org/Apt) as an example</i>), and some niche distributions use source code based package managers. Solstice OS is a source code based distribution. For a user to install a package, they must compile the source code into a binary that their [CPU (a.k.a central processing unit)](https://www.ibm.com/think/topics/central-processing-unit) can understand and execute. <i>Trust me, this is not as complicated as it sounds.</i> [Solpm](https://github.com/solsticelinux/solpm) (Solstice's package manager) handles the compilation and basic configuration for you.
